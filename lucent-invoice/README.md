# Lucent 請求書管理

Lucentの請求書作成・入金管理システム（MVP）。サーバー不要の静的Webアプリ。

## 使い方
`index.html` をブラウザで開くだけ（GitHub Pages等に置けばスマホからも使える）。

1. **設定** で振込先・インボイス登録番号を入力（振込先は個人情報なのでリポジトリには書いていない）
2. **新規作成** で請求先・明細（日付／車種・型式／部品／数量／単価）を入力
   - 取引先は保存時に自動登録。次回からは候補選択で住所・TEL/FAXが自動入力
   - 新しい行は前の行の日付・車種を引き継ぐ
   - 「税込合計を〇〇円にそろえる」で最終行の単価を自動調整（例：80,000円ぴったり）
3. プレビューで **印刷 / PDF保存**（A4・1枚）
4. 入金があったら **入金済にする**。ホームで未入金・期限超過・月別売上を確認

## 仕様メモ
- 消費税：小計×税率、端数は切り捨て（設定で変更可）。No.345（小計72,728／税7,272／合計80,000）と同じ計算
- 請求書番号は自動採番（初期値346）
- 支払期限の初期値は翌月末（設定で当月末／記載なしに変更可）
- データはブラウザのlocalStorageに保存。**設定 → バックアップ** でJSONを書き出し／読み込み
- 一覧から会計ソフト・税理士向けにCSV出力（Excelで文字化けしないBOM付き）

## 今後の拡張候補

## MakeLeapsからの取り込み（今年の売上などを反映）
MakeLeapsのAPIで請求書を取り出し、このアプリに追加する。APIキーはMacの中だけで使い、どこにも保存しない。

1. MakeLeapsの「APIキー」画面で **クライアントID** と **クライアントシークレット** を確認
2. Macのターミナルで実行：
   ```
   cd ~/maruchu-hp && git pull
   cd lucent-invoice/tools
   python3 makeleaps_export.py          # 今年分（--all で全期間、--since 2025-01-01 で期間指定）
   ```
   ID／シークレットを聞かれるので貼り付ける → `makeleaps-export.json` ができる
3. 請求書管理の **設定 → MakeLeapsデータを取り込む** でそのファイルを選ぶ

- 何度取り込んでも重複しない（MakeLeapsの書類IDで判定し、最新内容に更新）
- このアプリで編集した請求書は上書きしない（MakeLeaps側で入金済になった時だけ入金状態を反映）
- 金額はMakeLeaps上の小計・消費税・合計をそのまま使う（明細を編集すると再計算に切り替わる）
- 取り込むのは「請求書」だけ（見積書・納品書などは除外）
- 書き出しファイルは顧客情報を含むので `.gitignore` 済み。うまく取れない項目があれば `--raw` で生データを出して確認する
