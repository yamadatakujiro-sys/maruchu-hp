# 塗装原価メーター — 訪問デモ用モック（仮）

板金塗装の**塗料原価・見積もりを見える化**する独立システム（案件：塗料原価の見える化システム）の、
**現場ヒアリング用のクリック可能なモック**。実装ではなく、見た目と流れを見せて反応をもらうためのもの。

- ファイル：`index.html`（単体で動く。ビルド不要。ブラウザで開くだけ）
- 全数値・品名は**ダミー**。実際の製品仕様ではない。
- スマホ／タブレットでそのまま見せられるレスポンシブUI。

## 4画面（デモの流れ）
1. **原価マスタ** … 「内容量 × 缶の値段 → 1gあたり単価」を自動計算（登録は最初の1回）。
2. **使用量入力** … 1台ごとに使った量(g)を入れると材料費が自動算出（＋−で触って見せられる）。
3. **見積もり** … 材料費 ＋（作業時間 × レバレート）＋ 諸経費 ＝ 原価 → 提示見積もり。
   保険協定の値引き想定と「**ここから下は赤字**」ラインをゲージで可視化。
4. **実績・予測** … 台数が貯まると「この作業なら材料費 約◯円」を見積もり前に予測。

## 「盛らない」前提を画面内に明記
1g未満の超微量は計量が要る／精度は入力次第／既存見積ソフトとの自動連携は未約束／
値引きを止める機能ではなく交渉の根拠を作る、を④画面に記載。

## 使い方（訪問時）
- スマホのブラウザで公開URL（または本ファイル）を開く → 4画面をタップで見せる。
- ②で数字を触って材料費・見積もりが即座に変わるのを見せると伝わりやすい。
- 見た反応（生の声）は案件ファイル `../../docs/CASE-paint-cost-system.md` に**そのまま**追記する。
