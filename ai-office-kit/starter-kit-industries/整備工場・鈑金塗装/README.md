# 業種テンプレ：整備工場・鈑金塗装（オーナー用・顧客には渡さない）

> これは**差分だけ**を持つフォルダです（オーバーレイ方式）。
> 基本キット `../../starter-kit/` に**上書き**して使います。
> こうしておくと、基本キットを改善したとき**全業種に自動で行き渡る**（コピーの管理地獄を避ける）。

---

## 納品物の作り方（3コマンド）

```bash
# ① 顧客用リポジトリをクローン（先にGitHubでPrivateリポジトリを作る）
cd ~ && git clone https://github.com/yamadatakujiro-sys/<顧客リポジトリ名>.git

# ② 基本キット → 業種テンプレ の順で重ねる（この順番が重要）
cp -R ~/maruchu-hp/ai-office-kit/starter-kit/. ~/<顧客リポジトリ名>/
cp -R "~/maruchu-hp/ai-office-kit/starter-kit-industries/整備工場・鈑金塗装/." ~/<顧客リポジトリ名>/
rm -f ~/<顧客リポジトリ名>/README.md   # ← このオーナー用READMEは顧客に渡さない

# ③ 基本キットのREADMEを戻して push
cp ~/maruchu-hp/ai-office-kit/starter-kit/README.md ~/<顧客リポジトリ名>/README.md
cd ~/<顧客リポジトリ名> && git add -A && git commit -m "初期構築（整備工場・鈑金塗装）" && git branch -M main && git push -u origin main
```

> ⚠️ **キットは必ずリポジトリ直下**に置く。奥のフォルダに入れると `CLAUDE.md` と
> `.claude/agents/` が読まれず、AI社員が動かない（検証済み）。

## 追加社員が「有料オプション」になる理由

この2名は**この業種の売上に直結する**ので、価値が説明しやすい＝課金しやすい。

- **見積説明担当**：お客さんが工場に来る前の不安は「見積より高くなる」「不要な工事を勧められる」。
  それを消す説明文があるだけで**成約率とクレーム率が変わる**。
- **来店促進担当**：整備工場の売上は**車検・点検のリピート**で決まる。
  新規集客より、すでに来た人に思い出してもらう方が確実で安い。

商談ではこう言える：
> 「御社の業種に合わせて、**見積の説明**と**車検の案内**を専門にやる担当も入れてあります」
