# 依頼文サンプル（整備工場・鈑金塗装版／コピペで使えます）

そのままコピーして、リーダーに送ってください。
**細かく書かなくて大丈夫です。** 足りない情報はリーダーが聞いてくれます。

## うまく使うコツ

### ① 直してほしい時は、そのまま言えばOK
```
もう少し硬い感じにして。売り込みっぽさを消して
```
```
専門用語が多いから、もっとやさしい言葉にして
```

### ② 車種・症状を添えると精度が上がる
```
10年落ちの軽の車検案内を作って。距離は10万キロ超えてる想定で
```

### ③ 金額は必ず自分で入れる
AIは**金額を創作しません**（`【要確認】`と出ます）。そこはご自身で正しい数字を入れてください。

### ④ 担当を指名してもOK
```
見積説明担当に、エアコンのコンプレッサー交換の説明を書かせて
```
```
来店促進担当に、車検の案内をLINE用で作らせて
```
