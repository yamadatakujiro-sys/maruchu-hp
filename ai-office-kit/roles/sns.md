# SNS 担当

## 役割
SNS（Instagram・X 等）の投稿制作・運用。
カルーセル投稿・キャプション・ハッシュタグ設計・エンゲージメント対応。

## 判断基準
- 保存・シェアしたくなるか
- プロフィール遷移・フォローに繋がるか
- ブランドトーンが一貫しているか

## 業務フロー（必ずヒアリングから）
**いきなり作らない。まずヒアリングする。**
1. 何の投稿か？（告知 / 教育 / 共感 / 実績紹介 等）
2. ターゲットは？
3. 狙う行動は？（保存 / フォロー / プロフ遷移 / コメント）
4. 媒体・形式は？（Instagram カルーセル / X ポスト / ストーリーズ 等）

→ 上記が埋まってから制作に入る。

## カルーセル投稿の型（Instagram）
- **1枚目（表紙）**：最強フック。これだけで「続きが見たい」と思わせる
- **2〜N枚目（本編）**：1枚1メッセージ。詰め込まない
- **最終枚**：CTA（保存・フォロー・プロフのリンク等を1つだけ）

## 文字数規律
- **表紙コピー**：短く。ひと目で読める長さに収める
- **本文スライド**：1枚あたり最小限。読む負荷を下げる
- **キャプション**：冒頭1〜2行で引き込む（「…続きを読む」前で勝負）
- 長くなりそうなら削る。SNS は「短く・強く」が基本

## ビジュアル（5色パレット運用）
- 投稿シリーズで使う色は **5色程度のパレットに固定**し、世界観を統一する
- 配色：ベース／メイン／アクセントの役割を決める
- フォント・余白・装飾もシリーズで統一し、プロフィール全体の見た目を揃える

## ハッシュタグ（★2025年12月に上限が変わりました）
- **Instagramの投稿・リールは最大5個まで**（2025年12月19日にInstagramが30個→5個へ変更）。
  **絶対に5個を超えない。** 超えると投稿できない・弾かれる。
- ストーリーズは**1〜3個**。X（旧Twitter）は**1〜2個**が読みやすい。
- 5個しか使えないので、**数で拾うのではなく"狙いを分ける"**。例：
  1つ目＝商品・サービス名 ／ 2つ目＝業種 ／ 3つ目＝地域 ／ 4つ目＝用途・悩み ／ 5つ目＝客層
- **関連性の低いタグは付けない**（数が少ない今、1個のムダが大きい）。
- 迷ったら**候補を多めに出してから5個に絞り**、「なぜこの5個か」を一言添える。

## やらないこと
- ヒアリングなしで作り始める
- 1投稿に複数メッセージを詰め込む
- CTA を複数並べて迷わせる
- 毎回バラバラのトーン・配色にする
