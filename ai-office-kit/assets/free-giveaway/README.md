# 無料配布物（試乗）｜求人票をスマホで3分で作る

> **★これは「集客のためのリードマグネット」ではない。【試乗】である。**
> 目的は**AIを1回だけ使ってもらうこと**。売ることではない。

## 🚨なぜこれを作ったのか（設計の根拠）

**オーナー実感（2026-08-17）：**
> **「商品は良い物なんだけど、AIをなんだかよく分かってない人が多すぎて伝わらない」**

**これが本当のボトルネックだった。** 価格でも商品でもない。

**AIを一度も使ったことがない人に「AIのキット」を売るのは、
車に乗ったことがない人に車を売るのと同じ。→ 試乗が必要。**

**成功体験を1回作れば、そこから先は売れる。済んでいない相手には何をしても売れない。**
配達先の手応えが薄いのも、SNSのアンケートが0件だったのも、原因はここだと考えている。

### マス配布の「無料特典」とは違う（ここを混同しない）

| | ネットに落ちてるプロンプト集 | **これ** |
|---|---|---|
| 量 | 100個 | **1個だけ** |
| 対象 | 誰にでも | **鈑金屋・整備工場だけ** |
| 目的 | リスト取り | **AIを1回使わせる** |
| 結果 | フォルダに入って終わり | **今日1枚作れる** |

**100個もらったら誰も使わない。1つなら試せる。** 目的が「使ってもらうこと」なので、数はマイナス。

⚠️**キット本体（`starter-kit/`）は無料で渡さない。** これは**別に作った1点物**。
（`docs/DIRECT-OFFER.md` の「無料配布はしない」判断と矛盾しない）

## なぜ「求人票」にしたか

| 理由 | 中身 |
|---|---|
| **一番わかりやすい** | 箇条書き5行 → 求人票1枚。**AIを知らない人にも"魔法"に見える** |
| **業界共通の痛み** | 整備士・鈑金工不足。募集していなくても**「人いないよねぇ」は必ず返ってくる** |
| **危ない判断が入らない** | 金額・車検可否・保険を触らない＝**そのまま出しても事故らない** |
| **既存ソフトと競合しない** | 求人原稿を自動で作るソフトは現場に入っていない |

🚫**「車検・点検の案内文」は却下した。** 管理ソフトからハガキ・DMが既に出ている可能性があり、
**鈑金屋の見積で外したのと同じ失敗**（＝すでに解決している困りごとを課題として出す）になりかねない。

## ★★設計上の絶対条件

**Claudeの無料版で動く内容にする。** 試乗に課金を要求したら試乗にならない。
→ 配布物には「**無料のままで大丈夫です**」と明記してある。
⚠️ここを崩すと配布物の意味が消える。文言を変えるときも必ず守る。

## 使い方①：配達先・仕入れ先で渡す（★これが本命）

**話を聞いてもらう必要がない。渡すだけでいい。**

```
「これ、うちで使ってるやつ。求人の原稿がスマホで作れるから、もし人募集するとき使って」
```

- **売り込まない。** 値段の話もしない。**渡して終わりでいい**
- 印刷して**何枚か車に積んでおく**（`kyujin.pdf`）
- もし相手が興味を持ったら、**その場でスマホで実際にやって見せる**
  → `docs/DIRECT-OFFER.md`「反論①」の対処①と同じ

⚠️**「使ってみた」の一言が返ってきた相手が、次の見込み客。** そこから初めて商品の話をする。

## 使い方②：Instagram・Xで配る

**アンケート投稿と違い、相手に得がある**（＝行動する理由がある）。

### 投稿文（そのまま貼る／Xは140字以内・機械計測済み）

**X用（109字／上限140字・機械計測済み）**
```
整備士・鈑金工の求人票が、スマホで3分で作れる指示文を作りました。

コピーして店の情報を書き換えるだけです。アプリは無料で使えます。

要る方いますか？リプかDMで送ります。

うちも自分の店で毎日使ってるやつです。
```

**Instagram用（キャプション）**
```
整備士・鈑金工の求人票が、スマホで3分で作れる指示文を作りました。

コピーして、店名・給与・休みのところを自分の店のものに書き換えるだけです。
アプリは無料で使えるので、お金はかかりません。

「アットホームな職場」みたいな中身のない言葉は使わない、
書いていない条件を勝手に作らない、というルールを入れてあります。
分からない所は「要確認」と出るので、そのまま出しても事故りません。

うちも自分の店で毎日使ってるやつです。

要る方、コメントかDMで「ほしい」と送ってください。画像でお渡しします。

#鈑金塗装 #自動車整備 #整備工場 #求人 #業務効率化
```

- **画像は `kyujin.png` を1枚そのまま添える**（4:5ではないので、Instagramはフィードだと上下が切れる。
  → **ストーリーズか、DMで送る**のが確実。フィードに出すなら4:5版を別途作る）
- ハッシュタグは**5個**（Instagramの上限）

⚠️**DMで送るのが一番確実。** Instagramはキャプションのリンクが押せないので、
「ほしい」と言ってくれた人に**画像を直接送る**のがロスが少ない。

## 使い方③：反応が返ってきたら

| 相手の反応 | 返し方 |
|---|---|
| 「ほしい」 | 画像を送るだけ。**売り込まない** |
| 「使ってみた」 | ★**ここが本番。**「他に文章で困ってることある？」と聞く |
| 「うまくいかない」 | ★**一番おいしい。** 実際に見て直してあげる＝**そのまま試乗の続き** |
| 「AIって何？」 | 説明しない。**その場でやって見せる**（口で説明すると伝わらない） |

**「使ってみた」が返ってきた相手だけが見込み客。** それ以外に商品の話をしても、今までと同じ結果になる。
