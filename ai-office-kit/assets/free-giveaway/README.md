### ★設計の誤りと修正

**「書いていない条件を勝手に作らない」は正しい。
だが結果として「要確認」が並んだ半分空っぽの書類が出るのが間違いだった。**

**捏造しないこと ≠ 骨だけ出すこと。**

```
❌ 「勤務時間：要確認」と出して終わり
✅ AIが1問ずつ聞いて、全部そろってから750字を書く
```
→ **捏造せず、かつ完成品が出る。** しかも「質問に答えるだけ」なので、
**AIが分かっていない人にはむしろ簡単**（自由に書かせる方が難しい）。

**もう1つの修正**：プロは「和気あいあいとした職場」と書いている＝
初版のルール「中身のない言葉は使わない」は厳しすぎた。
正しくは **「抽象語だけで終わらせない。具体で裏付ける」**
（`和気あいあい`単体はNG／`20〜40代8名で昼食を一緒に取る`はOK）。

### 🚨教訓（同じ種類の失敗が3回目）
**業界向けの物は、その業界のプロの実物と並べて判定する。自分の中の基準で作らない。**
1回目＝鈑金屋の見積（ソフトで明細が出る）／2回目＝部品屋の在庫検索（本業＝経験）／
**3回目＝求人原稿（プロは750字使い切る）**。**毎回「実物を見ていない」ことが原因。**

## 🚨媒体側にもAIがある（engageの「カンタン入力」ボタン）

**「AIで文章が作れます」だけでは差別化にならない。** 媒体内に既にAI補助がある。

**勝てる点は1つだけ。** オーナーのブックマークに**求人媒体が4つ**
（クラッチ求人・Airwork・engage・Indeed）＝**同じ内容を4媒体に入れ直している**。
文字数も項目も全部違う。

> **1回答えれば4媒体ぶん出し分けられる。**
> **engageのAIはengageの中しか知らないので、これは絶対にできない。**

→ **これを配布物の主役にした**（表面の見出しが「4媒体ぶん」）。
⚠️**各媒体の書式ルールは断定していない**（実際の仕様を確認していないため）。
紙に書いたのは**「Airwork用に書き直して」と打つ**という**利用者側の操作**だけ。

## なぜ「求人票」にしたか

| 理由 | 中身 |
|---|---|
| **一番わかりやすい** | 質問に答えるだけで750字が埋まる。**AIを知らない人にも成果が見える** |
| **業界共通の痛み** | 整備士・鈑金工不足。募集していなくても**「人いないよねぇ」は必ず返ってくる** |
| **危ない判断が入らない** | 金額・車検可否・保険を触らない＝**そのまま出しても事故らない** |
| **4媒体問題が実在する** | 同じ内容を媒体ごとに入れ直す手間は**本人が実際にやっている** |

🚫**「車検・点検の案内文」は却下した。** 管理ソフトからハガキ・DMが既に出ている可能性があり、
**鈑金屋の見積で外したのと同じ失敗**（すでに解決している困りごとを課題として出す）になりかねない。

## 🚨【最重要・2026-08-19に判明】この紙は「渡す物」ではなく「見せる台本」

> **オーナー（現場20年）：「めんどくさいの塊は…新しい物や今回みたいなAIとかを
> めんどくさがる光景だよ。俺は現場で見ているから痛いくらいわかる。」**

**当初は「AIを知らないから伝わらない」と考えて試乗を作った。だが実際の障壁は違った。**

| 想定 | 実際 |
|---|---|
| **知らない**から伝わらない | ❌ |
| ★**新しいことをやるのが面倒** | ✅**知らない人には教えれば届く。面倒な人には教えても届かない** |

**この紙の手順は5手ある**（アプリを入れる→文をコピー→質問に答える→出た文をコピー→貼る）。
**めんどくさがる層には、この時点で多すぎる。渡すだけでは使われない。**

| ❌ | ✅ |
|---|---|
| 渡して、相手に使ってもらう | **その場で目の前でやって見せるための台本にする** |
| 相手が5手やる | **相手は見るだけ。手は0** |

→ **帰り際に置いてくるのは可。だが本番は「その場で1本作ってしまう」こと。**
**相手の手間をゼロにする。**

⚠️**短期の指標も変える**＝「何件売れたか」ではなく**「何人が実際に触ったか」**。
**この業界は心を開くまで時間がかかる**（オーナー実感）。**10件では判断できない。**
ただし**「触った人が1人も出ない」ならそこは問題。**

## 使い方①：配達先・仕入れ先で【見せる】（★これが本命）

**渡すだけでは使われない**（上の節）。**目標は"その場で1本作ってしまう"こと。**
ただし**いきなり実演を押し付けない。** 紙を出しながら一言かけて、反応を見る。

```
「これ、うちで使ってるやつ。求人の原稿がスマホで作れるんだけど」
（裏面を見せながら）「こういうのが3分くらいで出る」
```
→ 相手が**少しでも食いついたら、その場でスマホを出して1本作る。**
→ 興味がなさそうなら**紙だけ置いて終わる**（押さない。関係の方が大事）。

- **売り込まない。** 値段の話もしない
- 印刷して**何枚か車に積んでおく**（`kyujin.pdf`）
- 🚨**「渡して終わり」にしない。** 少しでも聞く姿勢があれば**その場でスマホで1本作って見せる。**
  **これが本番**（相手の手間がゼロになる唯一の形）→ `docs/DIRECT-OFFER.md`「反論①」の対処①

⚠️**「使ってみた」の一言が返ってきた相手が、次の見込み客。** そこから初めて商品の話をする。

## 使い方②：Instagram・Xで配る

**アンケート投稿と違い、相手に得がある**（＝行動する理由がある）。

### 投稿文（そのまま貼る／Xは140字以内・機械計測済み）

**X用（139字／上限140字・機械計測済み）**

```
そのあと一言足せば、Airworkやindeed用にも書き直してくれます。

```

**Instagram用（キャプション）**
```
整備士・鈑金工の求人原稿、engageの750字を埋めるのが大変じゃないですか。

質問に答えていくだけで埋まる指示文を作りました。
「1日の流れは？」「入庫は保険と自費どのくらい？」と1問ずつ聞いてくれるので、
思い出しながら答えるだけで750字がぜんぶ埋まります。

答えていない条件は勝手に足さないルールを入れてあるので、
盛った内容にならず、そのまま出しても事故りません。

そのあと「Airwork用に書き直して」と打てば、他の媒体用にも直してくれます。
1回答えれば4媒体ぶんです。

ChatGPTでもClaudeでも動きます。無料のままで大丈夫なので、お金はかかりません。
うちも自分の店で毎日使ってるやつです。

要る方、コメントかDMで「ほしい」と送ってください。画像でお渡しします。

#鈑金塗装 #自動車整備 #整備工場 #求人 #業務効率化
```

- **画像は `kyujin-2.png`（裏＝出力の実物）を先に見せる。** 手順書より効く
- A4比率なのでInstagramのフィードでは上下が切れる → **ストーリーズか、DMで送る**のが確実
  （フィードに出すなら4:5版を別途作る＝下記「次に作るもの」）
- ハッシュタグは**5個**（Instagramの上限）

⚠️**DMで送るのが一番確実。** Instagramはキャプションのリンクが押せないので、
「ほしい」と言ってくれた人に**画像を直接送る**のがロスが少ない。

## 使い方③：反応が返ってきたら

| 相手の反応 | 返し方 |
|---|---|
| 「ほしい」 | 画像を送るだけ。**売り込まない** |
