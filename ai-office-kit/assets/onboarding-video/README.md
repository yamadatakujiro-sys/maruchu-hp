# 使い方ガイド動画（字幕版）

**成果物：`使い方ガイド.mp4`**（1920×1080／30fps／**4分18秒**／約3MB／H.264＋無音トラック）

## これは何か

購入者に渡す**導入用の動画**。スライド17枚＋文字だけで構成した**字幕版（音声なし）**。

### なぜ音声なしにしたか（2026-08-12）
オーナーから「**自分の声がガサガサで聞き取りにくい。読み上げも動画も全部AIに任せたい**」との要望。
- この制作環境には**TTSエンジンもAPIキーも無い**ため、ここで音声を作ることはできない。
- 無料の抜け道（非公式TTS等）は**商用利用の規約リスク**があるため使わない
  （売り物の動画で規約リスクを負うのは、この事業の「誠実さ」方針と真逆）。
- → **文字で完結する字幕版**にした。**音がなくても内容は100%伝わる**設計にしてある。
- 副次的な利点：**音を出せない場所でも見られる**（電車・職場・深夜）。実用上むしろ有利。

## 🎵 BGMを付ける（2通り。用途が違うので使い分ける）

### A：YouTube上で直接付ける（5分・ブラウザだけで完結）
1. **YouTube Studio** →左メニュー**「コンテンツ」**→ この動画をクリック
2. 左メニュー**「エディタ」**→**「音声」**
3. 曲の一覧が出る → 曲にカーソルを合わせて**「追加」**
4. 下のタイムラインに帯が出る → **ドラッグして開始位置と長さを調整**
5. 帯の**「⋮」→「ミックス レベル」**で**音量を下げる**
6. **「保存」**（保存後、再処理されるので反映に少し時間がかかる）

> 出典：[オーディオ ライブラリの音楽と効果音を使用する（YouTubeヘルプ）](https://support.google.com/youtube/answer/3376882?hl=ja)

### B：音源をDLしてMP4に焼き込む（納品ファイルにも入る）
YouTube Studio の左メニュー**「オーディオ ライブラリ」**から曲を**ダウンロード**して、
このフォルダに `bgm.mp3` として置き、
```bash
bash build.sh bgm.mp3
```
**曲が短くても自動でループ**し、フェードイン2秒／フェードアウト3秒が付く。

**音量は倍率ではなく LUFS で指定**している（`build.sh` の `BGM_LOUDNESS`）。
倍率指定だと**曲を替えたときに音量が狂う**ため（実測で確認：同じ倍率でも曲によって20dB以上ズレる）。
| 設定 | 用途 |
|---|---|
| `-18`（既定） | **今の字幕版**（ナレーション無し）でちょうどよい背景音量。実測 -17.3dB |
| `-30` | あとからナレーションを乗せる場合はここまで下げる |

### なぜ両方やるか
納品は基本 YouTube の限定公開URLだが、**3MBなのでファイルを直接渡す運用も想定している**。
**Aだけだと、直接渡したMP4は無音のまま。** Bまでやると納品物として完成する。

### 🚫 やってはいけないこと：YouTube動画から音を抜く

**気に入った曲のYouTube動画を見つけても、そこから音声を抽出して使うのは不可。**
理由は2つ：①**YouTubeの規約**（ダウンロードボタンの無い動画の保存は認められていない）
②**曲そのものの著作権**（そのチャンネルが権利者とは限らない）。

これは**購入者に配る納品物**に入れる音源。ここを崩すと、後で動画を全部作り直すことになる。
（`SALES-CHANNELS.md` でヤフオクの規約を「自分で確認する」と決めたのと同じ原則）

### ✅ 正しい入手ルート（この順で当たる）

| 順 | ルート | 見るところ |
|---|---|---|
| 1 | **フリーBGM配布チャンネルなら、概要欄のリンク先（公式配布サイト）からDL** | DOVA-SYNDROME／MusMus／甘茶の音楽工房 など。**同じ曲を合法に入手できる**ので最有力 |
| 2 | **YouTube Studio →「オーディオ ライブラリ」** | ジャンル・ムードで検索。**DLボタン付き＝正規** |
| 3 | YouTube上だけで完結（Studio→エディタ→音声） | ⚠️**納品用MP4は無音のまま**になる |

**使えるか判定するときに見る3点：**
1. チャンネル名と曲名
2. 概要欄に「**商用利用可**」「**クレジット表記が必要**」「規約はこちら」の記述があるか
3. 配布サイトの利用規約（**商用OK／改変OK／クレジット要否**）

⚠️ **「Youtube オーディオライブラリ」という名前のチャンネルは公式ではない**（転載チャンネル）。
ただし**概要欄に「配布元」と「ダウンロードURL」が書かれている**ことが多く、**そこから正規の入手先が分かる**。
曲がオーディオライブラリの音源だと分かったら、**必ずYouTube Studioの本物のライブラリで検索してDLする。**

### ★採用する曲（2026-08-12・確認済み）
**`Hold on a Second` ／ John Deley and the 41 Players**
- ジャンル：ジャズ、ブルース ／ スタイル：**明るい** ／ 再生時間：**3分02秒**
- **配布元：Youtube Audio Library**（概要欄に明記・ダウンロードURLも `youtube.com/audiolibrary_...`）＝**正規音源**
- 取り方：**YouTube Studio →「オーディオ ライブラリ」→ 曲名で検索 → ⬇ でDL**
- ⬜ **DL画面で「帰属表示」欄を確認する。** 「必要」と書かれていたら**別の曲に替える**
  （購入者に配る納品物にクレジット義務を付けたくないため）
- ⚠️ **曲3分02秒 ＜ 動画4分18秒** なので**ループする**。`build.sh` は自動ループするが、
  **継ぎ目が目立つ場合はクロスフェードで滑らかにする**（合成後に必ず継ぎ目を聞いて判断）

### 選曲・音量の指針（この動画専用）
| 項目 | 指針 |
|---|---|
| ジャンル | **Ambient／Cinematic** の落ち着いた曲 |
| ムード | Calm／Inspirational。**盛り上げすぎない** |
| 歌詞 | **なし**（字幕を読む動画なので歌詞は邪魔） |
| 音量 | **控えめ**（YouTubeのミックスレベルなら20〜30%／Bなら volume=0.08 前後） |
| 長さ | 4分18秒あるので**ループしても違和感のない曲** |

⚠️ **一番大事な注意：「帰属表示が必要」と書かれた曲を選ぶと、説明欄へのクレジット記載が義務になる。**
この動画は**購入者に配る納品物**なので、**帰属表示が不要な曲を選ぶ**のが安全。

## あとから音声（ナレーション）を足す場合

この `使い方ガイド.mp4` を Vrew 等に読み込み、`docs/ONBOARDING-VIDEO-TTS.md` の
⓪〜⑤を貼ってAI音声を**上に乗せる**だけ。**土台は完成しているので作り直し不要。**
⚠️ Vrewの商用利用はLightプラン（月1,290円程度）から。無料プランは商用不可。

## 作り直す手順

```bash
cd ~/maruchu-hp/ai-office-kit/assets/onboarding-video
NODE_PATH="$(npm root -g)" node render.cjs   # slides.html → slide-01..17.png
bash build.sh                                 # PNG → 使い方ガイド.mp4
```

| ファイル | 役割 |
|---|---|
| `slides.html` | スライド本体（**文言を直すのはここ**） |
| `render.cjs` | HTML → PNG（playwright） |
| `build.sh` | PNG → MP4（ffmpeg）。**表示秒数は `DUR=(...)` で調整** |
| `slide-01..17.png` | 書き出したスライド（商談資料にも流用可） |
| `使い方ガイド.mp4` | ★納品する動画 |
