# 望月オート：体験デモ「みんなの工程ボード」

ホワイトボード → スマホ共有 → AI の**体験デモ**（設定ゼロ・スマホでURLを開くだけで動く）。
訪問時に社長のスマホで触ってもらう用。オーナー（タツヤ）が事前に自分で試す用。

- 本体：`board-demo.html`（単一HTML・ライブラリ不要・オフライン可）
- 公開Artifact URL：https://claude.ai/code/artifact/6fafa788-76eb-499d-9b3f-e382408f8628
  （※URLは再公開で変わり得る。最新は案件スレッドで管理）

## 1画面で伝える3つの価値
- 🅐 **共有ボード**：工程（列）×車（カード）。フェーズで色分け（受入/施工/仕上げ/完了）。
- 🅑 **喋る/打つと動く**：下のLINE風入力に「田中さんのハイエース 塗装終わった」→ 該当の車が自動で次工程へ。
- 🅒 **先回り通知**：納期の重なり・遅れ・本日納車をデータから自動で拾って上部に表示。

## デモの割り切り（盛らない）
- 車を動かす判断は、デモでは**端末内のキーワード解釈**（オフラインで確実に動くため）。
  本番はここを **Claude** が担当（言い回しの揺れ・音声にも強い）。
- 「きょう」は 8/13 に固定（納期の緊急度を安定表示するため）。
- 本番：入力＝いつものLINE／表＝Googleスプレッドシート。デモ画面内にもその旨を明記。

## 触り方（現場で見せる流れ）
1. 開くと実データが入って動いている状態。上に「先回り通知」。
2. 下の例文チップをタップ → カードが次工程へスッと移動、AIが返信。
3. 自由入力もOK（お名前 or 車種＋工程＋「終わった」）。
4. 「リセット」で最初の状態へ。
