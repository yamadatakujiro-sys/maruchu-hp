# Lucent（@lucent_autoparts）向け「部品屋のリアルなAI活用」シリーズ

> **狙い**：Lucentのフォロワー**503人＝ほぼ鈑金屋・整備屋・一部部品商**（オーナー確認）に、
> **AIで案内文・説明文が作れる**と知ってもらう。**売り込まない。「うちはこうしてる」の共有にする。**

## 🚨この使い方を守る（Lucentのブランドを壊さない）

| ✅ やる | ❌ やらない |
|---|---|
| 「うちはこうしてる」の実践共有 | 「AIで効率化できます！ご相談ください」＝商材っぽい売り込み |
| DMに誘導 | **プロフィール文・リンクを変える**（`lucent.base.ec`＝買取の導線。触らない） |
| 本業9：AI1 の比率（月2〜3本まで） | AI投稿だらけにする（フォロワーが離れる） |

**理由**：Lucentは**部品を買う人**がフォローしている。商材の宣伝が混ざると
「部品屋やめて情報商材始めたの？」になり、**20年の信用が変質する**。

### なぜアンケートなのか（第1弾と同じ理由）
タツさん自身は**中古部品商なので実感がある**が、**新品部品商・材料屋の当事者ではない**。
→ **推測で困りごとを書かない。**（`post-01.html` が不採用になったのと同じ轍を踏まない）

### 🚨【最重要】AIが入れる線・入れない線（2026-08-17・オーナー指摘で修正）

初版は「在庫・納期の問い合わせ対応」「品番・適合の確認」を**時間を取られる作業**として並べていた。
**これは間違い。** オーナー指摘：

> **「在庫あるって聞かれたのを調べて探すのが、中古/新品の部品屋さんの仕事なんだよね。
> ここは経験があるからAIが入ってこれない部分」**

つまり**本業そのものを「無駄な時間」扱いしていた**＝業界を分かっていない文章になる。

| | AIが入れない（人の仕事） | AIが入れる（AIの仕事） |
|---|---|---|
| 中身 | **探す・見極める・適合を判断する** | **毎回ほぼ同じ形で書く／打つ** |
| 根拠 | 年式・形状・相場が頭に入っている＝**経験** | 型が決まっている＝**繰り返し** |

→ **軸を「一番時間を取られるのは？」から「毎日、同じことの繰り返しになってる作業は？」に変更。**
オーナーの言葉そのまま＝**「毎日同じ作業をしてれば、AIなら全部自動化にできる」**。

**2枚目で先に「探して見極めるのは経験の仕事／ここは代わりがききません」と認める。**
これが**「分かってる人が書いてる」に見せる一番の要素**。否定から入らない。

リーチは**503人の13.5%＝実質68人前後**で、そのうち部品商は**"一部"**。

→ **選択肢の言葉を広く取って**1本に統合し、**⑤の自由記述で業種差を拾う**。

### この投稿で守っていること
- **売り込まない**（「うちはこうしてる」で終わる／申込導線を作らない）
- **金額を出さない**（¥5,000等は書かない。DMで話す）
- **効果を保証しない**（「値切られない」は自分の実感として書き、断定・保証はしない）
- **ハッシュタグ5個**（Instagramの上限。2025-12に30個→5個へ変更）
- **AIが金額・車検可否・保険を断定しない設計**に触れる ＝ 同業の一番の不安を先に消す
