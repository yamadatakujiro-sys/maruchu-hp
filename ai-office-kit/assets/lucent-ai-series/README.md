# Lucent（@lucent_autoparts）向け「部品屋のリアルなAI活用」シリーズ

> **狙い**：Lucentのフォロワー**503人＝ほぼ鈑金屋・整備屋・一部部品商**（オーナー確認）に、
> **AIで案内文・説明文が作れる**と知ってもらう。**売り込まない。「うちはこうしてる」の共有にする。**

## 🚨この使い方を守る（Lucentのブランドを壊さない）

| ✅ やる | ❌ やらない |
|---|---|
| 「うちはこうしてる」の実践共有 | 「AIで効率化できます！ご相談ください」＝商材っぽい売り込み |
| DMに誘導 | **プロフィール文・リンクを変える**（`lucent.base.ec`＝買取の導線。触らない） |
| 本業9：AI1 の比率（月2〜3本まで） | AI投稿だらけにする（フォロワーが離れる） |

**理由**：Lucentは**部品を買う人**がフォローしている。商材の宣伝が混ざると
「部品屋やめて情報商材始めたの？」になり、**20年の信用が変質する**。

## 📊 インサイトから読めたこと（2026-08-16・実測）

| 数字 | 意味 |
|---|---|
| フォロワー503人（ほぼ鈑金・整備・部品商） | **狙って作れない客リスト**。業種テンプレ第1弾のど真ん中 |
| **フォロワー以外 3.8%** | 🚨**新規にほぼ届かない**。発見タブ・ハッシュタグ流入がほぼゼロ |
| 閲覧者68／503（リーチ13.5%） | 投稿は「既存フォロワーに思い出してもらう」役 |
| いいね10／閲覧68（14%）・コメント0 | 見た人の反応は悪くない。**会話は起きていない** |

→ **結論：Lucentは「新規を取る装置」ではなく「既存503人に届ける装置」。**
**優先順位＝①配達のついでに見せる ②DM ③ストーリーズ ④投稿**。投稿だけで待つのが一番遅い。

## ★採用：アンケート投稿（2026-08-16）

> **狙い**：**困りごとを推測で書かない。本人たちに聞く。**
> 回収した言葉は **①次の投稿ネタ ②業種テンプレの改良 ③営業トーク** の3つに使える。
> **コメント0のアカウントに会話を作る**役でもある（インサイト参照）。

### 設計の原則（前回の失敗を踏まえて）
| やったこと | 理由 |
|---|---|
| **選択肢を「否定できない広い軸」にした**（電話・書類・募集・写真文章） | **特定の困りごとを断定しない**。前回は「見積が伝わらない」と決めつけて外した |
| **⑤「上にない！という方は一言で」を必ず入れた** | **こちらの選択肢が外れている前提**で作る |
| **「売り込みではありません」を明記** | 部品屋が同業に聞く形。Lucentのブランドを壊さない |
| Lucentの立場から入る（うちも手が止まる） | 上から教える形にしない |

⚠️ **選択肢①〜④はオーナーが現場の言葉に差し替えてよい**（`survey-feed.html` の `<li>` を書き換えて再実行）。

### 🎨配色：フィードは【明るいクリーム地】（2026-08-16 変更）
初版は濃紺の暗い配色で作ったが、**オーナー指摘＝「暗すぎて答えたくない」**。**正しい。**
アンケートは**答えてもらうのが目的**なので、**暗い＝重い＝答えたくない**では設計矛盾。
→ **クリーム地(#fdf6e9)＋濃紺の文字＋オレンジのアクセント＋角の丸い飾り**に変更。
**選択肢は白いカードに影を付けて"押せそう"に見せる**（answering を誘う）。
**ストーリーズも同じ明るい配色に統一済み**（オーナーが投稿し直すため・2026-08-16）。
> ⚠️他フォルダ（紺＋青＋アンバー）と配色が違うのは**意図的**。用途が違う。
> **アンケート素材は「答えてもらう」のが目的＝明るい配色**。これは今後も守る。

### ストーリーズの流し方（★これが一番答えが返る）
**画像は背景。投票・質問スタンプはアプリ側で貼る**（画像の中央〜下を空けてある＝スタンプ置き場）。

| # | 画像 | アプリで貼るスタンプ | 選択肢 |
|---|---|---|---|
| 1 | `q-story-1` | **アンケート（投票）** | `現場の作業` ／ `それ以外` |
| 2 | `q-story-2` | **アンケート（投票）** | `書類・入力` ／ `電話・連絡` |
| 3 | `q-story-3` | **アンケート（投票）** | `足りてる` ／ `足りない` |
| 4 | `q-story-4` | **質問スタンプ**（自由記述） | 「これ、なくなったら楽って作業ありますか？」 |

> 💡**2択は文字を打たせないので回答率が高い**。まず1〜3で数を取り、4で生の言葉を拾う。
> 💡ストーリーズは**投稿より届く**（インサイトでフォロワー以外3.8%＝投稿は新規に届かない）。

### フィード投稿のキャプション（そのまま貼る）

```
鈑金屋さん・整備士さんに聞きたいことがあります。

うちも、部品を出す・運ぶ以外のところで手が止まります。
連絡、書類、写真、文章。気づいたら夕方、みたいな日があります。

みなさんはどうですか？

現場作業以外で、一番時間を取られるのは？
① 電話・連絡のやり取り
② 書類・入力まわり
③ 人の募集
④ 写真や文章づくり
⑤ 上にない！という方は、ぜひ一言で

なぜ聞くかというと、いま うちの事務作業をAIにやらせる試しをしていて、
同業で同じところに時間を取られているなら、ちゃんと使える形にしたいからです。

売り込みではありません。まず実際のところを知りたいだけです。
番号だけでも、コメントかDMで教えてもらえたら助かります。
```

### 回収した答えの使い道（★ここまでやって初めて意味がある）
1. **一番多かった答えを、次の投稿1本にする**（今度は推測ではなく**現場の言葉**で書ける）
2. **`starter-kit-industries/整備工場・鈑金塗装/` の `会社情報.md`・依頼文サンプルに反映**＝商品が強くなる
3. **`docs/DIRECT-OFFER.md` の業種トークを、返ってきた言葉に差し替える**＝営業が刺さる
4. 答えてくれた人は**見込み客リスト**。DMで続きを話せる

### この投稿で守っていること
- **売り込まない**（「うちはこうしてる」で終わる／申込導線を作らない）
- **金額を出さない**（¥5,000等は書かない。DMで話す）
- **効果を保証しない**（「値切られない」は自分の実感として書き、断定・保証はしない）
- **ハッシュタグ5個**（Instagramの上限。2025-12に30個→5個へ変更）
- **AIが金額・車検可否・保険を断定しない設計**に触れる ＝ 同業の一番の不安を先に消す
