## じゃあAIは何ができるのか（ここが売り物になるかの分かれ目）

| | Siriだけ | AI |
|---|---|---|
| 喋って1件入れる | ✅ できる | できる |
| **1つの発話を2件に分ける**（「明日入庫、金曜出庫」） | ❌ | ✅ |
| 「来週の水曜の朝イチ」のような曖昧な言い方 | △ | ✅ |
| **★被りを見つける**（「その時間もう入ってます」） | ❌**できない** | ✅**できる** |
| 車両・作業内容を整理して備考に入れる | ❌ | ✅ |

**★相手の痛みは「連絡ミスと入出庫の被り」＝"入れること"ではなく"被りに気づくこと"。**
**そこはカレンダーを読んで判定する必要があるのでAIの領域。**
→ **売り物になるとしたら「喋って入れる」ではなく「被りを見つける」の方。**

## テスト手順（オーナーのスマホで・30分）

**★自分のスマホで動くのを見ないと、配達先で見せられない。実演の練習にもなる。**

1. **Claudeアプリ → 設定 → コネクタ → Google カレンダー を接続**
   （ChatGPTでも Connectors で同じことができる）
2. マイクを押して、こう喋る：
   ```
   明日の9時に田中さんのハイエース入庫、出るのは金曜の夕方。カレンダーに入れて
   ```
3. **入庫・出庫の2件に分かれて入るか**確認する
4. ★**ここが本番＝わざと被らせる。** 続けてこう送る：
   ```
   明日の9時に佐藤さんのプロボックスも入庫。カレンダーに入れて
   ```
   **8/20 9:00 には既に田中さんの入庫が入っている。**
   → **AIがそれに気づいて「その時間もう入ってます」と警告するか**が本番。

   | AIの反応 | 判定 |
   |---|---|
   | **被りを指摘してから確認してくる** | ✅**これが欲しかった機能** |
   | 黙って2件目を作る | ❌**その機能はない**（＝売り物にならない） |

⚠️**「被ってるのある？」と聞くだけでは弱いテストになる。**
カレンダーがほぼ空だと「被りはありません」で終わり、**検知能力を測れない。**
**必ず、わざと被らせて試す。**

**4が動けば、相手の痛みに届いたことになる。**
⚠️つまずいた箇所は記録する（**そこがそのまま顧客のつまずき所**になる）。

## ⚠️本当の壁は技術ではなく運用

- 複数人で使うには**全員が同じカレンダーを共有**する必要がある（Googleカレンダーの共有機能で可能）
- だが**現場の人が全員ちゃんと入れるか**——ここが本当の問題
- **入れない人が1人いたら、被り検知は意味を失う**

**「連絡ミス」の根っこは"そもそも記録しない人がいること"で、技術では解決しない。**
→ 相手に伝えるときも**ここは正直に言う。** 隠すと導入後に必ず揉める。

## ✅テスト結果（2026-08-19・オーナー実施／カレンダーAPIで実データを確認）

**投げた文はこれ1つだけ：**
> 「明日の9時に田中さんのハイエース入庫、出るのは金曜の夕方。カレンダーに入れて」

**入った予定（APIから取得した実データ）：**

| 予定 | 日時 |
|---|---|
| `田中さん ハイエース 入庫` | **2026-08-20 09:00–09:30** |
| `田中さん ハイエース 出庫（納車）` | **2026-08-21 17:00–17:30** |

| 項目 | 結果 | メモ |
|---|---|---|
| コネクタ接続 | ✅ | claude.ai の設定から接続 |
| 喋って（打って）予定が入る | ✅ | |
| **1発話→2件に分かれる** | ✅ | 入庫・出庫に正しく分割 |
| 日時の解釈 | ✅ | 「明日」→8/20、「**金曜の夕方**」→8/21 17:00 |
| ★**文脈の理解** | ✅ | **「（納車）」を自分で足した**＝出庫＝客に返すことだと理解している |
| **被りの検知** | ⬜**未実施** | ←**ここが本番。上の手順4でわざと被らせて試す** |
| つまずいた箇所 | なし | **顧客も同じ所でつまずくので、出たら必ず記録する** |

### ★「（納車）」の自動補足が一番の収穫
**こちらは「出るのは金曜の夕方」としか言っていない。**
それを **`出庫（納車）`** と書いたということは、**鈑金・整備の文脈で「出庫＝客に車を返す」と
理解している**ということ。**単なる文字起こしではない。ここがSiriとの差。**

⚠️テストで作った予定（8/20・8/21）は**消してよい。**
