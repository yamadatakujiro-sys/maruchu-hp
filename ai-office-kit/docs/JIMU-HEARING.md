# 事務作業ヒアリング（板金屋・整備屋の社長に、LINEで聞く）

## これは何か
**現場の手仕事ではなく、事務（電話・予約・書類・入出庫管理など）の中で
「これが一番大変」「自動になったら楽」な作業を聞き出すためのLINE文面。**
送り先＝**仕入れ先・配達先の知り合い（板金屋・整備屋の社長・経営者クラス）**。

⚠️**今回の目的は「声を集めること」だけ。** 売り込まない・実演しない・商品の話をしない。
返ってきたら **「ありがとう」で止める**（下記「返ってきたら」参照）。

## なぜ事務なのか（業界の声で裏が取れている）
- 現役の職人が「**鈑金塗装はAIに侵食されにくい**」と明言（現場＝経験の仕事）。
- 一方 triple_trucks さんは自分から「**入出庫の予定を喋るだけでカレンダーを埋めてほしい。
  人が増えると連絡ミスと被りが起きる**」と言ってきた＝**事務はAIが一番効く**。
- → **現場では引く。事務で聞く。** ここが線引き。

## そのまま送れるLINE文面（社長・経営者向け）

```
おつかれさまです、ルーセントの山田です🙇

今、現場の作業じゃなくて
"会社の事務まわり"をAIで楽にできないか
いろいろ試してます。

もし1つだけ教えてもらえたら嬉しいんですが、

　会社の中で、現場じゃない事務作業で
　「これが一番、人手と時間を食ってる」
　「これ自動になったら楽なのに」

って思うこと、何かありますか？

例えばこんなやつです👇
・電話や予約の受付
・入庫／納車の予定管理（ダブりが起きる）
・見積書・請求書・納品書づくり
・部品の発注や在庫の確認
・車検や保険の書類
・給与や勤怠、日報の集計

「特にない」でも全然大丈夫です🙆
```

## 仕込み（一語ずつ意味がある）
| 仕込み | 理由 |
|---|---|
| 例を6つ並べる | 事務は「当たり前すぎて」大変だと気づかない。**選択肢を見せると思い出す** |
| 全部「事務」に絞る | 現場（手仕事）を入れると「そこはAI無理」と即閉じる |
| 「人手と時間を食ってる」で聞く | 社長はコストで見る。**自分の面倒より会社のコストの方が答えやすい** |
| **見積の"金額を決める"は例に入れない** | 「売上に直結するから任せられない」と言われた領域。**"書類を作る"事務はOK、"いくらにするか"は聞かない** |
| 「特にないでも大丈夫」で締める | 打ち消しの前置き（押し売りではない等）を書かず、**答えるハードルだけ下げる** |

## 返ってきたら（★今回はここで止める）
1. **「ありがとう」で受ける。** その場で作って見せない。商品の話をしない。
2. 相手が言った作業を**そのままの言葉で** `docs/LUCENT-X-PLAN.md` の業界の声のところに記録する
   （＝triple_trucks・sedeino16 と同じ扱い。**n を増やすのが目的**）。
3. **同じ作業が複数人から出たら**、そこが本命の入口。そのとき初めて「作って見せる」を考える。

⚠️**1人の要望で商品を作らない**（post-01 で存在しない困りごとを作った失敗の再発防止）。
**2人目が同じことを言うまでは"記録"だけ。**

## 送り方のコツ
- **1対1で送る。** 一斉送信にしない（見られている感が出ると答えない）。
- **1日2〜3人まで。** 数を撒くより、返事に丁寧に反応する方が次に繋がる。
- 返事が来なくても追わない。**「特にない」も立派なデータ**（事務に困っていない＝別の入口を探す）。
