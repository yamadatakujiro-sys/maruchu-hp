## 🚨最初に：診断を間違えないこと

**オーナー報告：買取の営業はInstagram・Xから一度も成約していない（0件）。**

これを「**買取の発信が悪かった**」と読むのは**誤診**。原因は**内容ではなく母数と需要の性質**。

| | 実測 |
|---|---|
| X `@hellolucent` | **162投稿 → 32フォロワー** |
| Instagram `@lucent_autoparts` | 503フォロワー・**リーチ68人(13.5%)**・フォロワー以外3.8%・コメント0 |

買取の需要は**タイミング依存**。鈑金屋が「**今まさに**眠ってるパーツを処分したい」状態にあるのは年に数回。

```
68人 × 今そのタイミングの人(数%) × 実際に動く人(数%) ≒ ほぼ0
```

→ **0件は統計的に予想どおり。** 投稿が悪かった証拠にはならない。
→ ⚠️**だから内容をAIに替えても、同じ68人なので同じ壁に当たる。**
**「内容を変えれば売れる」と思って落胆するのを防ぐため、この認識を先に置く。**

## それでもAIを混ぜるのは正しい（本当の理由）

| | 買取 | AI（事務作業） |
|---|---|---|
| 見込み客の条件 | 今まさに処分したいパーツがある | **毎日事務作業をしている** |
| 該当する人の割合 | 年に数回・少数 | **ほぼ全員・常時** |

**同じ68人に当てるなら、常時該当する話の方が当たる確率が高い。**
＝正しい理由は「買取が売れないから」ではなく **「AIの方が母数の少なさに強い」**。

## 方針：「買取を減らす」ではなく「買取投稿の役割を変える」

| | 扱い | 理由 |
|---|---|---|
| ❌ 「買います！DMください」型の**営業投稿** | **減らす** | 実測で効いていない |
| ✅ **現場の実物投稿**（入荷／判別／補修） | **維持する** | **「本物の部品屋だ」という証明**＝AIの話が刺さる唯一の土台 |
| ➕ **AI活用の実践共有** | **足す** | 常時該当する話＝当たる確率が高い |

🚨**現場投稿を消してはいけない。** 20年の現場経験が**この商品の唯一の差別化**。
現場の話が消えると、ただの**「AIを売ってる人」＝情報商材**に見える。**それが一番避けたい状態。**

###### 🚨「できません」と「できます」の間を取る（2026-08-18・オーナー指摘）
