## 🚨最初に：診断を間違えないこと

**オーナー報告：買取の営業はInstagram・Xから一度も成約していない（0件）。**

これを「**買取の発信が悪かった**」と読むのは**誤診**。原因は**内容ではなく母数と需要の性質**。

| | 実測 |
|---|---|
| X `@hellolucent` | **162投稿 → 32フォロワー** |
| Instagram `@lucent_autoparts` | 503フォロワー・**リーチ68人(13.5%)**・フォロワー以外3.8%・コメント0 |

買取の需要は**タイミング依存**。鈑金屋が「**今まさに**眠ってるパーツを処分したい」状態にあるのは年に数回。

```
68人 × 今そのタイミングの人(数%) × 実際に動く人(数%) ≒ ほぼ0
```

→ **0件は統計的に予想どおり。** 投稿が悪かった証拠にはならない。
→ ⚠️**だから内容をAIに替えても、同じ68人なので同じ壁に当たる。**
**「内容を変えれば売れる」と思って落胆するのを防ぐため、この認識を先に置く。**

## それでもAIを混ぜるのは正しい（本当の理由）

| | 買取 | AI（事務作業） |
|---|---|---|
| 見込み客の条件 | 今まさに処分したいパーツがある | **毎日事務作業をしている** |
| 該当する人の割合 | 年に数回・少数 | **ほぼ全員・常時** |

**同じ68人に当てるなら、常時該当する話の方が当たる確率が高い。**
＝正しい理由は「買取が売れないから」ではなく **「AIの方が母数の少なさに強い」**。

## 方針：「買取を減らす」ではなく「買取投稿の役割を変える」

| | 扱い | 理由 |
|---|---|---|
| ❌ 「買います！DMください」型の**営業投稿** | **減らす** | 実測で効いていない |

| ➕ **AI活用の実践共有** | **足す** | 常時該当する話＝当たる確率が高い |

🚨**現場投稿を消してはいけない。** 20年の現場経験が**この商品の唯一の差別化**。
現場の話が消えると、ただの**「AIを売ってる人」＝情報商材**に見える。**それが一番避けたい状態。**

## 🚨【文章のルール】打ち消しの前置きを書かない（2026-08-18・オーナー指摘）

初稿には **「押し売りではないので、要らなければ流してください」** と書いていた。
**オーナー指摘：「元々無料配布だから、押し売りって言葉必要かな？？」→ 正しい。削った。**

**打ち消しは、打ち消したい疑いを自分から持ち出す。**

| ❌ 書かない | なぜ | ✅ こう書く |
|---|---|---|
| 「押し売りではないので」 | **「押し売り」という言葉が頭に残る。** 書かなければ最初から浮かばない | 「よかったら送ります」 |
| 「怪しいものではありません」 | 怪しいと思わせる | （何も書かない） |
| 「無理にとは言いませんが」 | 押している自覚があると伝わる | 「要る方いますか？」 |
| 「素人なので間違ってたらすみません」 | **自分の信用を先に削る** | そのまま書く |

**本当に無料なら、堂々と出したほうが信用される。**
⚠️これは**全ての営業文・投稿・配布物に効くルール**。`DIRECT-OFFER.md` や
`LAUNCH-ANNOUNCEMENT.md` を書き換えるときも同じ基準で見る。
（※「売り込みではありません」を**投稿本文**に入れるのは別の話＝
アンケートで**回答者の警戒を外す目的**なので、そこは意図的に残している。
違いは**「相手に何かを渡す場面」では言い訳を書かない**ということ）

#### 返事が来たときの動き
| 相手の返事 | 返し方 |
|---|---|
| 具体的な作業を書いてくれた | **お礼＋その作業を1つ実際に作って見せる**（＝その場が試乗になる） |
| 「AIとか分からん」 | **説明しない。** 作ったものを見せる |
| 「うちは困ってない」 | **食い下がらない。**「ですよね、失礼しました」で終える |
| 同じ答えが複数来た | ★**次の無料配布物のネタが確定した**ということ |

⚠️**返ってきた言葉は"そのまま"記録する。** 言い換えると価値が消える。
記録先＝**このドキュメントの「実データ」節**（上）と `assets/lucent-ai-series/README.md`。

##### 🚨否定的な返事が来たときの返し方（★ここを間違えると終わる）

**説得しない。全部その通りだと認めて終える。**
相手が**分かった上で「今は無理」と言っている**場合、反論すると信用が消える。

**返信案（2026-08-18・Threads／441字）※オーナーがまだ送っていない**
```
ありがとうございます。すごく納得です。

見積ソフトの件、まさにそうですよね。
うちも鈑金屋さんの見積を見ると、脱着も交換も塗装も明細できれいに出てるので、

売上に直結するところを容易に任せられない、というのも分かります。

逆に言うと、任せられるのは売上に関係ないところなのかな、と思っていて。

```

**この返信で守っていること**
- **相手の3点すべてを認めている**（否定ゼロ）
- **見積ソフトの話に具体で乗る**（脱着・交換・塗装＝業界を知っている証明）
- **商品の話をしない。配布物も出さない**
- 最後に**自分の実例だけ置く**（求人＝売上に直結しない仕事）＝**押していない**

⚠️**配布物を出すのは、この返信の後に相手が何か返してきてから。**
いきなり出すと「やっぱり売り込みか」になり、**一番いい見込み客を1人失う。**
