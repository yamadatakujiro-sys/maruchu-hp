## この案件は何か（一言）
静岡の板金塗装会社「**望月オート**」（mochizuki-auto.com）向け。
**ホワイトボードでの納車・工程管理を、全社員のスマホで共有できるAIの仕組み**にする提案。
※女性の職人さんが多く、雰囲気のとても良い会社。**AIで業務効率化を"全部やりたい"くらい前向きな社長**。

## 困りごと（芯は1個）
> 会社は**ホワイトボードで納車・工程を管理**（大きいモニターに表示）。**会社に来ないと見えない**。
> 外出すると今どの車がどうなってるか分からず、**帰社するか電話**するしかない。
> → **ホワイトボードを全社員のスマホに持ち歩けるようにしたい。**

## 解決の方向（★確定）
**🅐 既製品でタダで"体感"してもらう → その上に 🅑🅒 のAIを乗せる。**
- **🅐 スマホで見る共有ボード（主役）**：使うのは **Googleスプレッドシート**（Excelみたいなもの＝みんな知ってる／新アプリを覚えない）。列＝工程（入庫→分解→板金→塗装→組付→検査→納車待ち→納車済）、車＝行。リンク1本で全員のスマホに。
  - ✅確定：**Trello等のカンバンアプリは使わない**。板金屋さんが見慣れないアプリに拒否反応を起こすため。
- **🅑 喋るだけでボードが動く（AIの出番）**：LINEに「田中さんのハイエース塗装終わった」→ Claudeが判断して該当の車を次の工程へ自動移動。入力の手間を消す。
- **🅒 先回り通知**：「納車まであと1日なのに塗装で止まってる」「同日に納車3台被り」→ LINE通知。既製品に無い価値。

### LINEのつなぎ方（🅑の中身）
社員の普段のLINEに「相談相手（AI）」を1人足すだけ。新アプリは入れない。
1. 会社用LINE（公式アカウント/グループ）を用意 → 社員は友だち追加/参加するだけ。
2. 社員が現場から「◯◯、塗装終わった」と普通に打つ/喋る。
3. 裏で Claude が読んで判断（この車・次は組付）。
4. AIが Googleスプレッドシートの該当の車を自動で動かす。
5. 全員のスマホの表が即更新。🅒通知も同じLINEに届く。
- 技術裏側（タツ用メモ・PDFには載せない）：LINE Messaging API → Webhook → Claude → Google Sheets API。オーナーが既に持つ「Claude＋LINE」の応用でゼロから新技術ではない。

## 本番Bot（★仕事として制作開始・2026-09）
- オーナー方針：**無料テストではなく「仕事」として本番構成で作る**（クライアントもLINEでやりたい意向・有償依頼）。

  - 構成：LINE Messaging API → Webhook(このBot) → **Claude(Haiku)が意味を解釈** → **Google Sheets API**で工程ボード更新 → 返信。先回り通知は `bin/notify.mjs`（cron）でLINE push。
  - AIは「どの車をどの工程へ」の**判断だけ**、シート更新はコードが確定的に実行（暴走防止）。
  - 工程名は `config/board.config.json` の `stages` に集約＝**訪問で実際の呼び方が分かったら差し替えるだけ**。
  - セルフテスト（鍵不要）：`node scripts/selftest.mjs`（現状 全14件パス）。
- 立ち上げ方針（オーナー決定）：**①まずMac＋cloudflaredトンネル ②まずオーナー名義**で動かす → OKなら本番はクラウド＋クライアント名義へ。
- ★**クライアントのPCはWindows**（2026-09-04判明）。ただしBot本体はクライアントPCで動かさない＝**本番はクラウド一択**。クライアントが触るのはLINE（スマホ）とGoogleスプレッドシート（ブラウザ）だけなのでOS無関係。今日のコード・鍵・シート・LINE設定は全部クラウドへそのまま流用可（変わるのは"動かす場所"のみ）。
  - 手順書＝`products/mochizuki-board-bot/SETUP.md`（Google/LINE/Anthropicの取得から検証・テスト・通知cron・本番移行まで）。
- ✅ **2026-09-04：本番Bot 実機で開通（E2E成功）**。オーナー名義・Mac＋cloudflaredで、
  LINE「田中さんのハイエース塗装終わった」→ Claude解釈 → Googleスプレッドシートの工程が塗装→組付けに自動更新 → LINE返信、まで確認。
  - 使用アカウント（オーナー名義・テスト）：LINE公式「モチヅキオートボディー様 工程ボード」／GCPプロジェクト job-scout のサービスアカウント board-bot／Anthropic Haiku。

- ★**フルでも月1万円いかないくらいで1社回せる。**
- ★**「Claude Codeのプラン(Pro/Max)」と「本番運用のAPIキー」は別物**：Claude Code＝作る道具（5時間制限あり・本番に使わない・Max不要）。本番LINE Bot＝Anthropic APIキー(従量・制限なし)。
