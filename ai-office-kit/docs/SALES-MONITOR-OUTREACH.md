# 創業モニター 直接オファー・キット（実績0→1の最短ルート）

> 目的：最初の1〜2件を「創業モニター」で獲得し、**実績＋お客様の声**を作る。
> それが、ココナラもSNSも一気に効かせる"燃料"になる（実績0のうちは何を撒いても弱い）。
> 方針：押し売り・情報商材っぽさは出さない（差別化方針3b＝誠実・信頼）。

---

## 1. モニターの設計（何を・いくらで・代わりに何をもらう）
- **提供**：初期構築を**無料**（通常¥39,000）でお試し。最初の1か月の運用も無料 or ¥9,800。
  ※ここは自由に調整可。"最初の2社だけの創業特典"と数量限定にすると背中を押せる。
- **代わりにもらう3つ**：
  1. 正直な**感想**（良かった点・いまいちな点の両方）
  2. できれば「**お客様の声**」＝サービス紹介に載せる許可（顔出し・社名は任意）
  3. 改善点の**フィードバック**（次の商品磨きに使う）
- **数**：まず**先着2〜3社**。埋まったら通常価格に。

---

## 2. 誰に声かける（リストの作り方）
**濃い順に、まず3〜5人だけ**紙に書き出す。いきなり広げない。

**優先順（濃い＝信頼が既にある人から）：**
1. 取引先・同業の社長（現場20年の人脈＝最強の資産）
2. 地元の事業者仲間・前職や現場の知り合い
3. 友人・家族で事業をやっている人
4. X/Instagram・LINEで既に少し繋がっている事業者
5. 名刺交換した人・過去に相談を受けた人

**刺さりやすい業種（"制作が発生＋ITが得意でない"層）：**
美容室 / 飲食店 / 整備工場 / 工務店・リフォーム / 教室・スクール / 士業 / EC・ネットショップ個人 など

**声かけ相手のチェック（3つ以上当てはまれば◎）：**
- [ ] 一人〜少人数でやっている（手が足りない）
- [ ] SNS投稿・チラシ・画像・LPなど"作るもの"が発生する
- [ ] ITやデザインが得意ではない（＝代行の価値が高い）
- [ ] あなたの顔・人柄を知っている（＝モニター0→1に最適）

## 3. オファー文（4パターン・そのまま使える）

### A. 親しい人へ｜LINE・対面（カジュアル）
```
お疲れさま！ 実は最近、"LINEで指示するだけでAIチームが
SNS投稿・画像・チラシ・LPを作ってくれる" サービスを始めてん。

いま立ち上げで、モニターを数社さがしてて——
もし良かったら [お名前] のとこで 無料で1件、試しに作らせてほしい！

インスタ投稿でもチラシでも、"作るの地味にめんどい"やつある？
使った感想だけもらえたら嬉しい。興味あれば「やってみる」って返して🙏
```

### B. 少し距離のある事業者へ｜DM・メッセージ（丁寧）
```
突然のご連絡失礼します。現場20年＋AIで、会社の困りごとを解決する
仕事をしている[お名前]と申します。

このたび、LINEで指示するだけでAIチームがSNS投稿・画像・LP等を
作成・納品する「代行サービス」を始めました。

立ち上げにあたり、モニターとして数社さまに無料（特別価格）で
お試しいただいています。[相手の業種]でしたら、
[例：インスタ投稿の作成／チラシ／メニュー画像]あたりでお役に立てそうです。

ご興味あれば、一度15分ほどお話（LINEでも大丈夫です）できませんか？
使った感想をいただくのが条件で、費用はいただきません。
```

### C. 対面・電話トーク（流れ）
1. 近況の雑談から入る（いきなり売り込まない）
2. 「最近こういうサービス始めてん」＋スマホでデモ動画を見せる
3. 「[相手]の[業種]なら、[具体例：インスタ投稿/チラシ]が作れるよ」
4. 「立ち上げのモニターで、**無料で1件作らせて**。試して感想くれたら嬉しい」
5. 「もし気に入ったら、"お客様の声"だけ協力してくれると助かる」

### D. Facebook等の知人向け｜一斉告知
```
【モニター募集】
LINEで指示するだけで、SNS投稿・画像・チラシ・LPを作る
"AI社員チーム"の代行サービスを始めました。

立ち上げ記念で、先着2〜3社さまを 無料 でお試し。
「作るのが追いつかない」個人事業主・中小企業の方、
"作ってほしいもの"がある方は、コメントかDMください！
（使った感想をいただくのが条件です）
```

## 4. 送り方のコツ
- **濃い人から順に、1人ずつ**送る（一斉より個別の方が刺さる）。
- **断られて当たり前**。3〜5人送って1件動けば大成功。数を淡々と。
- 相手の**具体的な"作りたいもの"を一緒に決める**（例：インスタ投稿3本／チラシ1枚）と、話が前に進む。
- 押さない。「興味あれば」で終える。追いかけない。

---

## 5. 成約したら：お客様の声のもらい方（納品後に送る）
```
先日はモニターのご協力ありがとうございました！
よろしければ、下の3つを一言ずついただけると嬉しいです😊
（サービス紹介に載せてOKか／お名前・社名は出してOKかも教えてください）

① 使う前は、どんなことに困っていましたか？
② 使ってみて、どうでしたか？
③ どんな人におすすめしたいですか？
```
→ もらった声は、ココナラ・X・LP・チラシの**すべてに使える最強の素材**。

## 6. 次の一手（モニター実績ができたら）
- お客様の声を**ココナラの「よくある質問」下や画像**に反映
- Xで「モニター事例：[業種]の[成果物]を作りました」を投稿（実演より事例が刺さる）
- 2件貯まったら創業特典を終了し、通常価格（初期¥39,000＋月¥9,800）へ
