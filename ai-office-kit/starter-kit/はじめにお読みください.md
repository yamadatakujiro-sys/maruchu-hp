# はじめにお読みください（3ステップで始められます）

> 🎥 **急いでいる方は、まず「使い方動画（約5分）」をご覧ください。**
> 　　▶ （納品時に動画のURLをお渡しします）
> 　　これを見れば、この先を読まなくても使い始められます。

このフォルダが、**御社専属のAIチーム**です。
デザイナー・ライター・SNS担当など**8人のAI社員**が入っています。

使い方はかんたんで、**リーダーに話しかけるだけ**。リーダーが担当に振り分けて、仕上げて返します。

---

## 準備（初回だけ・15分ほど）

### ① Claude Code を入れる
- パソコンに **Claude Code**（Anthropic公式アプリ）をインストールします。**Windows・Mac どちらでもOK**。
- あわせて **Claude の有料プラン契約**が必要です（月額はお客様ご負担／お一人分で使えます）。
  ※AIの頭脳部分の契約です。ここだけはお客様名義でお願いします。

### ② このフォルダを好きな場所に置く
- デスクトップでも書類フォルダでも構いません。**フォルダ名や中身は変えないでください。**

### ③ Claude Code でこのフォルダを開く
- Claude Code を起動 →「フォルダを開く」でこのフォルダを選びます。
- 準備はこれで完了です。

---

## 使ってみる

開いた画面に、こう話しかけてください👇

```
インスタの投稿を3本つくって
```

するとリーダーが「SNS担当に作らせます」と動き出し、できあがった投稿文を返します。

**もっと例を見たいときは `依頼文サンプル.md` を開いてください。**（コピペで使えます）

---

## できあがったものの受け取り方（ここ大事です）

### ① いちばんかんたん：**画面からコピーする**
できあがった投稿文・記事などは、**チャットの画面に全文が出ます。**
そのままコピーして、Instagramや資料に貼り付けてください。**これだけで完結します。**

### ② ファイルとして残したいとき
成果物は `納品/` フォルダにも保存されますが、**この画面での作業は一時的な保存**のため、
残すには画面下の **「PRを作成」→「マージ」** を押してください。押すとファイルが正式に保存されます。

> 💡 **押さなくても大丈夫です。** 上の①（コピー）で普通に使えます。
> 「あとから見返したい」「記録として残したい」ときだけ押してください。

## 大事なファイル

| ファイル | 中身 |
|---|---|
| `会社情報.md` | 御社の商品・お客さん・トーンを書いたファイル。**AIチーム全員がここを読んで仕事します** |
| `依頼文サンプル.md` | そのままコピペで使える頼み方の例 |
| `困ったときは.md` | うまくいかない時の対処 |
| `納品/` | できあがった成果物が入るフォルダ |

### 情報が変わったら
`会社情報.md` を開いて書き換えるだけです。**次の依頼から反映されます。**
（新メニューが増えた、キャンペーンが変わった、など）

## 困ったときは

**この画面で、そのまま質問してください。**
```
エラーが出て動きません
```
と書けば、リーダーが `困ったときは.md` を見て案内します。

それでも解決しない場合は、**画面のスクリーンショット**を添えてご連絡ください。

- AIが作るものは**そのまま使える保証はありません**。公開前にご自身で内容を確認してください。
- 実績・数字・お客様の声は、AIが勝手に作らないよう設定してあります。**「要確認」と出たら事実をご確認ください。**
