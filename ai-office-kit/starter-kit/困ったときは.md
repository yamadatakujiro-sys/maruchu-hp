# 困ったときは

> **このファイルはAIリーダーが読んで案内するためのものです。**
> お客様は「動きません」「エラーが出ました」と画面に書くだけでOKです。

---

## リーダーへの指示
オーナーが「動かない」「エラー」「おかしい」と言った時は、
**下記から症状に近いものを探して、順番に1つずつ案内してください。**
一度に全部を並べず、**1つ試してもらって結果を聞く**形で進めます。
どれにも当てはまらない場合は、**エラーメッセージをそのまま見せてもらってください。**

---

## 症状1：「ログインしてください」「認証エラー」と出る
Claudeのログインが切れています（数週間〜で切れることがあります）。
- Claude Code の画面で **`/login`** と入力して送信 → ブラウザが開くのでログイン
- 「Claude account with subscription」を選ぶ
- 戻ってきたら、もう一度依頼を送る

## 症状2：「上限に達しました」「limit」と出る
Claudeの利用量の上限です。
- **時間をおいてから**再度お試しください（数時間でリセットされます）
- よく使う場合は、Claudeの上位プランをご検討ください
- 節約のコツ：会話が長くなったら **`/clear`** で区切ると軽くなります

## 症状3：AIが会社のことを分かっていない／トーンが違う
`会社情報.md` が空欄のままか、内容が古い可能性があります。
- `会社情報.md` を開いて、商品・お客さん・トーン・NG表現を埋めてもらう
- 埋めたら、もう一度依頼を送る（次の依頼から反映されます）

## 症状4：担当に振らず、リーダーが自分で作ってしまう
- 「**デザイナーに作らせて**」のように**担当を指名**してもらう
- リーダーは自分で成果物を作らないルールです。指名すれば必ず担当が動きます

## 症状5：成果物が見つからない
- `納品/` フォルダの中に、日付つきの名前で保存されています
- 見つからない時は「**保存先のファイル名を教えて**」と聞いてもらう

## 症状6：作ったものが事実と違う／実績の数字が違う
AIは**数字や実績を創作しない**設定ですが、念のため公開前に必ずご確認ください。
- 「**要確認**」と書かれた箇所は、事実をお客様側でご確認ください
- 違っていたら、正しい情報を伝えて作り直させてください

## 症状7：画像がうまく作れない／文字が切れる
- サイズを指定してもらう（例：「インスタ用の正方形1080×1080で」）
- 「**文字を少なくして大きく**」と伝えると読みやすくなります

## 症状8：Claude Code が起動しない／フォルダを開けない
- Claude Code を最新版に更新してもらう
- パソコンを再起動してから、もう一度開いてもらう
- フォルダの場所を移動した場合は、**移動後のフォルダを開き直す**

---

## それでも解決しないとき
リーダーは、次の3つをまとめてオーナーに伝えてください。
1. どんな操作をしたか
2. 画面に出ているエラーメッセージ（そのままの文字）
3. 試したこと

そのうえで「**この内容を販売元にご連絡ください**」と案内してください。
（スクリーンショットを添えていただくと解決が早くなります）
