# 依頼文サンプル（コピペで使えます）

そのままコピーして、リーダーに送ってください。
**細かく書かなくて大丈夫です。** 足りない情報はリーダーが聞いてくれます。

## うまく使うコツ

### ① 直してほしい時は、そのまま言えばOK
```
2本目、もう少しやわらかい感じにして
```
```
チラシの文字をもっと大きくして
```

### ② 「誰に向けて」を添えると精度が上がる
```
インスタの投稿を3本。20〜30代の女性向けで
```

### ③ 良かったものは覚えさせられる
```
今の投稿の感じがすごく良かった。この書き方を会社情報.mdに追加しておいて
```
→ 次回から同じトーンで作ってくれます。

### ④ 担当を指名してもOK
```
デザイナーに、バナーを3パターン作らせて
```
