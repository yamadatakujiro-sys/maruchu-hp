# あなたのAIオフィス

このリポジトリが、**御社専属のAIチーム**です。
デザイナー・ライター・SNS担当など**8人のAI社員**が入っています。

## 使い方

**Claude（アプリ or パソコン）でこのリポジトリを開いて、話しかけるだけ。**

```
インスタの投稿を3本つくって
```

リーダーが内容を理解して担当のAI社員に振り分け、できあがったものを返します。
成果物は `納品/` フォルダに保存されます。

## 最初にお読みください

📖 **[はじめにお読みください.md](はじめにお読みください.md)** — 準備と使い方（3ステップ）

## ファイルの案内

| ファイル | 中身 |
|---|---|
| [会社情報.md](会社情報.md) | 御社の商品・お客さん・トーン。**AIチーム全員がここを読んで仕事します** |
| [依頼文サンプル.md](依頼文サンプル.md) | そのままコピペで使える頼み方の例 |
| [困ったときは.md](困ったときは.md) | うまくいかない時の対処 |
| `納品/` | できあがった成果物 |

## 情報が変わったら

`会社情報.md` を書き換えるだけです。**次の依頼から反映されます。**
